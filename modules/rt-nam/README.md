# WaveNet NAM Model

The code here is based on the [RTNeural-NAM project](https://github.com/jatinchowdhury18/RTNeural-NAM), and has been modified to support the generation of RTNeural-compatible objects from .nam files. Use `nam_to_header.py` to convert your .nam files, and the top-level README for a an example of the C++ API (compile-time only).
